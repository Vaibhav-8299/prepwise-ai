# PrepWise AI 🚀

> AI-Powered Interview Preparation Platform

## Overview

PrepWise AI helps job seekers prepare for interviews using artificial intelligence — from resume analysis to mock interviews with real-time feedback.

## Tech Stack

| Layer | Technology |
|---|---|
| **Backend** | .NET 8 Web API |
| **Frontend** | Angular 21 |
| **Database** | MySQL 8 (EF Core + Pomelo) |
| **AI Engine** | Google Gemini API |
| **Code Runner** | Judge0 API |
| **Auth** | JWT + Refresh Tokens + BCrypt |
| **Email** | MailKit (SMTP) |

## Features

| Feature | Description |
|---|---|
| 🔐 Authentication | JWT + Refresh Tokens + Email OTP Verification |
| 📄 Resume Analyzer | Upload PDF → AI scores it → improvement suggestions |
| 📚 Interview Prep | AI generates theory, HR, SQL & coding Q&A |
| 🎤 Mock Interview | AI evaluates answers with voice input support |
| 💻 Code Editor | Monaco Editor + Judge0 for live code execution |
| 🗺️ Study Roadmap | AI-generated personalized learning plan |
| 👨‍💼 Admin Panel | User management + platform statistics |
| 📧 Email Scorecard | Auto-email mock test results |
